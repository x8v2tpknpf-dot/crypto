# BingX 合約交易機器人

基於 **MACD + RSI + EMA25** 三指標共振策略的 BingX 永續合約自動交易機器人。

---

## 功能特色

- **三指標共振**：MACD 金叉/死叉 + RSI 超賣/超買回歸 + EMA25 趨勢過濾
- **自動開倉 / 平倉**：偵測反向信號時自動平倉
- **自動停損**：開倉後即掛 `STOP_MARKET` 停損單
- **風險控管**：每筆交易最多虧損總資金的 1%
- **Telegram 通知**：開倉、平倉、錯誤即時推送
- **回測模組**：從 BingX 抓歷史 K 線，輸出完整績效報告

## 設定步驟

### 1. 申請 BingX API 金鑰

1. 登入 [BingX](https://bingx.com) → 個人中心 → API 管理
2. 新建 API，開啟「合約交易」權限
3. 將 `API_KEY` 與 `SECRET_KEY` 填入 `config.py`

### 2. 設定 Telegram Bot

1. 在 Telegram 與 `@BotFather` 對話，建立新 Bot，取得 `Token`
2. 傳訊息給你的 Bot，再用以下網址取得 `chat_id`：
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
3. 將 `TELEGRAM_TOKEN` 與 `TELEGRAM_CHAT_ID` 填入 `config.py`

### 3. 調整交易參數（config.py）

| 參數 | 說明 | 預設值 |
|------|------|--------|
| `SYMBOL` | 交易對 | `BTC-USDT` |
| `INTERVAL` | K 線週期 | `1h` |
| `LEVERAGE` | 槓桿倍數 | `5` |
| `RISK_PCT` | 每筆風險比例 | `0.01`（1%）|
| `STOP_LOSS_PCT` | 停損距離 | `0.02`（2%）|
| `CHECK_INTERVAL` | 檢查間隔（秒）| `3600` |

## 策略邏輯

### 開多條件（三項同時成立）
1. **MACD 金叉**：MACD 線由下往上穿越信號線
2. **RSI 超賣回升**：RSI 前一根 < 30，當前 ≥ 30
3. **價格在 EMA25 上方**

### 開空條件（三項同時成立）
1. **MACD 死叉**：MACD 線由上往下穿越信號線
2. **RSI 超買回落**：RSI 前一根 > 70，當前 ≤ 70
3. **價格在 EMA25 下方**

### 平倉條件
- 出現反向信號時平倉
- 停損觸發（STOP_MARKET 掛單）

## 風險警示

> ⚠️ **本程式僅供學習與研究用途，使用前請充分了解加密貨幣合約交易的高風險性。過去回測績效不代表未來獲利，請自行承擔交易風險。**

## 常見問題

**Q：機器人一直顯示「無信號」？**
A：三項指標需同時共振才會觸發信號，1h 時間框架信號頻率較低屬正常現象。

**Q：如何修改為其他交易對？**
A：修改 `config.py` 的 `SYMBOL` 參數即可，例如 `ETH-USDT`。

**Q：回測失敗顯示「無法取得 K 線資料」？**
A：請確認 API Key 正確，且 BingX 帳號已完成 KYC 驗證。
